# Bundled fonts

- Baloo 2: rounded title, weight 800. Source: https://github.com/google/fonts/tree/main/ofl/baloo2
- Nunito: supporting text, regular weight. Source: https://github.com/google/fonts/tree/main/ofl/nunito

Both are variable TrueType fonts distributed under the SIL Open Font License.
The original licenses and copyright notices are included beside the font files.
