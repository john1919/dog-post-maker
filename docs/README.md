# Volunteer post maker demo

Static HTML/CSS/JavaScript and prepared public demonstration assets. No Python
server, OpenAI requests, credentials, tracking or persistent browser storage.
Only same-origin static files are fetched. All user edits and approval names
disappear on refresh; a demo approval displays Azra's example video for any dog.

The local tool supplies the AI scoring, checks, repairs, factual caption writing
and actual dog-specific video generation. This demo illustrates the review flow.

Assets are compressed copies: photos/options are at most 800 pixels per side,
and the silent sample video is 720 × 900. Original source files and metadata are
not included. See the root README for refreshing the export.
